# PCF-001 Parent Plan

## Status

`ReadyForRiskTriage`

## Requirements

- `FR-001`: Restore the producer snapshot to `Active` while preserving `correlation_id`.
- `FR-002`: Allow consumer push only while the consumer is `Accepting`.
- `AC-001`: The production startup path restores the producer, reaches `Accepting`, and returns `Accepted`.
- `AC-002`: A non-accepting consumer state rejects the push.
- `CASE-001`: Active producer snapshot produces the accepted postcondition.
- `CASE-002`: Recovering consumer state produces the rejection postcondition.
- `XC-001`: `snapshot_state` and `correlation_id` remain continuous across producer, consumer, and production entrypoint boundaries.

## Scope

Implement and verify `SL-001` before `SL-002`, then verify the production entrypoint across both slices.
